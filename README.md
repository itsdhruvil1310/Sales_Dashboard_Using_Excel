# 📊 Sales Dashboard – Excel

## 📌 Overview

This project is an interactive **Sales Dashboard created using Microsoft Excel**.  
It converts raw sales data into meaningful visual insights to help analyze sales performance, target achievement, and individual sales executive performance.

The dashboard is designed to provide a quick and clear overview of key sales KPIs and help support data-driven business decisions.

## 🎯 Objectives

- Analyze overall sales performance
- Compare sales performance of different executives
- Track sales targets and achievements
- Identify top-performing sales executives
- Identify performance gaps
- Present business insights through an interactive dashboard

## 📈 Dashboard Features

- Total Sales Analysis
- Sales Executive Performance
- Target vs. Actual Sales
- Target Hit Percentage
- Away From Target Percentage
- Daily Sales Analysis
- Interactive charts and visualizations
- KPI-based performance tracking

## 🧮 Key KPIs

### Total Sales
Calculates the total sales generated by each sales executive.

### Target Hit %
Measures how much of the assigned sales target has been achieved.

**Formula:**

`Target Hit % = Total Sales / Sales Target × 100`

### Away From Target %
Shows the percentage by which sales performance is below the assigned target.

**Formula:**

`Away From Target % = 100% - Target Hit %`

## 💡 Key Insights

The dashboard helps users:

- Find the highest-performing sales executives
- Compare actual sales against targets
- Identify employees who exceeded their targets
- Identify employees who are below their targets
- Understand sales performance trends
